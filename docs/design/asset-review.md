# Enkryon Asset Review

## Purpose

This document records the current asset direction for Enkryon before applying the design system to the app UI.

The goal is not to redesign the icon and splash screen immediately. The goal is to use them as the visual direction for the in-app UI.

## Asset Decision

The current launcher icon and splash screen will both be kept.

Even though there are some visual inconsistencies between them, they both point toward the same general brand direction:

- Premium finance identity
- Deep emerald base
- Gold accent
- Darker, calmer visual tone
- Trust and growth feeling

The app UI should adapt to this direction instead of forcing the assets to match the current pale-green interface.

## Current Problem

The current in-app UI does not fully match the icon and splash direction.

Icon / splash: premium emerald and gold
In-app UI: lighter pale-green prototype style
